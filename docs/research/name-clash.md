# Name check: "Five Nines"

Accessed 2026-09-30. Informational only: the name is locked, nothing changes because of this. Not legal advice.

## Findings

- **No video game called "Five Nines" turned up** in web searches for the exact title, including Steam and itch.io.
- **Nearest game title found: "Nine Nines"**, a tower defense game by Badjano Entertainment. It came out on Steam on 2024-10-21.
  - Source: https://store.steampowered.com/app/2880240/Nine_Nines/ (page opened)
- **Nearest itch.io name found: a developer account called "FiveNine"** (fivenine.itch.io), with an action game named "Shattered Dimensions".
  - Source: search result only, page not opened.
- **"Nine to Five"** is a 2023 multiplayer FPS by Redhill Games. Similar words, different order.
  - Source: https://en.wikipedia.org/wiki/Nine_to_Five_(video_game) (search result)
- **Trademarks:**
  - A search result says a "FIVE NINES" trademark application was filed 2000-03-14 (serial 75943979) for multimedia software, owner M/C Venture Partners IV. **I couldn't open the record to check its status** because Justia returned HTTP 403.

  - **Five9, Inc.** is a contact center software company, so the name is close but written differently.
- **"Five nines" is also a common industry term** for 99.999% availability. That fits the game's theme, but it also makes the name hard to search for.
